# hop

## 0.3.2

### Patch Changes

- fb1f2b6: Typing a name that starts like a sum, such as 7-Zip, now lists the app instead of calculator history.
- 6d36519: Fixed the System commands, Calculator and Check every day switches in Settings saving the old value instead of the new one.

## 0.3.1

### Patch Changes

- 2b83132: Results you pick for a search now come first the next time you type it.

## 0.3.0

### Minor Changes

- c65ebd3: Added calculator history: your last results show under a sum, type = to see them all, Enter edits one and ⌘Enter inserts its result.
- e44f2dd: Added System Settings sections to search: type a section's name, such as Privacy, to open it.
- df92ccc: Added system commands to search: Lock Screen, Sleep, Restart, Shut Down, Log Out and Empty Trash; the last four ask for a second Enter.

## 0.2.0

### Minor Changes

- a50e36f: Added a calculator: type a sum such as 2+3*4 to see the answer above the apps, and press Enter to copy it.
- b53ce3e: Added ⌘1–9 to open a result directly; hold ⌘ to see the numbers.

## 0.1.2

### Patch Changes

- 4cc5ccf: Made hop easier to read and to use with VoiceOver: dimmed text in the palette has more contrast, Settings starts reading at its first section and names the current hotkey, and Settings no longer leaves empty space below its content.

## 0.1.1

### Patch Changes

- 197aa6f: Documented how to install hop from a release and get past the first-launch Gatekeeper block.

## 0.1.0

### Minor Changes

- 77743b2: Added a menu-bar icon and a Settings window for the hotkey, start at login (on by default), extra folders to index, apps to hide, the theme and the palette style (⌘, in the palette opens it, Esc closes it); quitting from the menu-bar icon no longer loses your last launch.
- f2bdb26: hop checked for updates daily and on request, showed a found update as a pill in the palette and in the menu-bar icon, and installed it from a new What's new window.

### Patch Changes

- 022dac2: The palette now finds your apps by name, localized name or initials, opens them with Enter, reveals them in Finder with ⌘Enter, and lists your most used apps when nothing is typed.
- 2d6c7a7: Restyled Settings like macOS System Settings, with grouped rows and on/off switches in light and dark.
- eb2aca6: Pressing ⌥Space now shows an empty palette; Esc or clicking away hides it.
